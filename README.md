# 🏪 알바 근무표 자동 생성기 (Smart Shift Scheduler)

> 조건만 입력하면 공평하고 빈틈없는 알바 근무표를 0.1초 만에 자동으로 짜주는 단일 웹페이지 애플리케이션입니다.  
> 서버나 데이터베이스, 별도 프로그램 설치 없이 브라우저에서 `index.html` 파일을 열기만 하면 즉시 동작합니다.

---

## ✨ 주요 기능

1. **요일 그룹별 근무타임 분리**:
   - 평일(월~금)과 주말(토·일)의 영업시간 및 필요 인원을 각각 다르게 설정 가능.
   - 어떤 그룹에도 속하지 않는 요일은 매장 휴무일로 자동 처리.

2. **6가지 스마트 배정 규칙 (순수 JavaScript 알고리즘)**:
   - 하루 최대 타임 수 제한 (1~3타임)
   - 하루 두 번 출근 금지 (연속 타임만 배정하여 중간 비는 시간 방지)
   - 클로픈(마감 후 다음날 오픈) 금지 (최소 11시간 휴식 보장)
   - 연속 근무일 상한 (최대 6일 등 주중 휴무 보장)
   - 주간 최대 근무시간 상한 (최대 40시간 등)
   - 주말 배정 균등화

3. **주간 근무시간 & 주휴수당 대상 표시**:
   - 근무자별 주간 총 근로시간 집계.
   - 주 15시간 이상 근무자에게 `주휴수당 대상` 뱃지 표시.

4. **미배정(인원 부족) 원인 진단 툴팁**:
   - 규칙에 걸려 자리를 채우지 못한 경우, 빨간색 뱃지에 마우스를 올리면 구체적인 제외 사유 안내.

5. **공유 및 내보내기/불러오기**:
   - 카카오톡 단톡방 공유용 텍스트 복사.
   - A4 맞춤 인쇄 / PDF 저장 지원.
   - 업종별 빠른 시작 프리셋 (편의점, 카페, 음식점).
   - 다중 매장 슬롯 저장 및 `.json` 설정 파일 내보내기/불러오기 지원.

---

## 🚀 실행 방법

별도의 빌드 과정이나 서버 실행 없이, **`index.html` 파일을 더블 클릭**하여 웹 브라우저(크롬, 엣지, 사파리 등)에서 열면 바로 사용할 수 있습니다.
